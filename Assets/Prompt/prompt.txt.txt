## 2. The vision
A vibrant **cyberpunk metropolis at night** — neon pinks/blues/purples/yellows. Tight,
zoomed-in side-scroller with **multi-layer parallax**. A sleek **cybernetic runner** with a
**blue energy trail that intensifies with speed**.
- **Seamless start:** centered, semi-transparent **"Hold on… Press to Start" loading-bar**
  overlay that vanishes the instant the player starts, dropping straight into a sprint.
- **Obstacles:** glowing **neon-red blocks** (jump over) and **low red laser beams**
  (crouch under), with precise timing.
- **Collectibles (risk/reward):** **Golden Stars** = flat score bonus. **Speed Rush green
  chevrons** = scroll speed spikes (less reaction time) but score multiplies massively
  while active.
- **Minimalist UI:** **top-right** readout = **FPS + rapidly ticking Score**. On Speed
  Rush, a **"SPEED RUSH"** label **drops from top-center** with a **depleting energy bar**.

  (music stops); land = `drop_001`; jump = `maximize_001`, double-jump = `maximize_004`.

  (`PlayerController.crouchHeightScale`, default 0.55) to pass under lasers; restores on
  release/jump/reset. Needs a **Capsule or Box** collider; sets `isCrouching` animator bool
  only if that parameter exists. Use it — don't rebuild it.
- **Laser obstacle type (DONE in code):** `ObstacleSpawner` picks among
  `pipeObstaclePrefab` / `blockObstaclePrefab` / `laserObstaclePrefab` by
  `pipeWeight` / `blockWeight` / `laserWeight`; lasers spawn at `groundY + laserHeight`.
  Laser is unassigned by default (weight 0 = old behaviour) until you wire a prefab.
- **Driver scripts to wire:** `SpeedRushUI`, `FPSCounter`, `SpriteFlipbook`, `AutoDestroy`
  (+ `PickupSparkle.prefab`).
- **Code hooks:** `GameManager.SpeedRushActive`, `SpeedRushRemaining01`, `SpeedIntensity01`;

## 6. EDITOR TASKS

**B. Post-processing** — Add a **Global Volume** with **Bloom** (+ vignette/color) so neon

`Laser Height` so a standing player is hit but a **crouching** player passes; balance
`Pipe/Block/Laser Weight` (default 0.4/0.35/0.25).

**F. Collectibles** — Verify Star/SpeedRush spawn. Make **SpeedRush a green chevron/arrow**.

**G. HUD (top-right)** — Move/restyle the readout to **top-right**: TMP **Score** + a TMP

**H. Speed Rush UI** — Top-center **"SPEED RUSH"** label (RectTransform) + a **Filled Image**

**I. Start screen** — Build the centered **"Hold on… Press to Start"** semi-transparent

Write a small fill script if you want the bar to actually gate the start.

**J. Fonts** — Create the SDF assets (Section 5) and assign to every TMP text.

**K. Audio polish** — Confirm the wired SFX feel right; swap if any clip doesn't suit.
